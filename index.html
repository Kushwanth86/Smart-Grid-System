06 / Behind the interface

From model signals
to meaningful decisions.

The website is the presentation layer. MATLAB/Simulink remains the simulation environment; its exported JSON provides the recorded traces and KPIs displayed here. The What-if lab is intentionally separated so demo interactions do not get mistaken for a new simulation run.

07 / Data integrity

Clarity before claims.

Simulation dashboards are useful only when a visitor can tell what is measured, what is inferred and what is unavailable.

How to read this dashboard

The page shows the values available in the supplied simulation JSON. Missing security and anomaly outputs are not guessed or replaced with status claims.

✓Recorded simulation: KPI values, time series and scenario comparisons loaded from dashboard_data.json.
✓Illustrative interaction: the What-if lab runs in the browser and is labeled separately.
✓Signal signs preserved: EV power values retain their recorded negative and positive signs.
✓No fabricated security result: unavailable cyber status is displayed as unavailable.
